## Vanishing-page bug — ROOT CAUSE FOUND + FIXED (2026-06-10)
**This corrects the earlier misdiagnosis.** Last session the "Team/Goals content appears then vanishes" symptom was written off as a harmless "preview pauses animations" artifact and patched cosmetically (PageEmpty cards). That was WRONG and the real bug shipped.
- **Real root cause:** the `.page-enter` (and `.stagger-in`) entrance animation in `global.css` animated **opacity from 0**. A CSS animation that is **paused or interrupted before completing** (tab backgrounded mid-navigation — the preview does this constantly, but a real browser can too on a slow/again-navigated load) holds the element at its current frame, i.e. **opacity 0**, with no `animation-fill-mode` to recover. `.app-content` (the whole page body) was the animated element, so the entire page went invisible. Confirmed by measuring `getComputedStyle('.app-content').opacity === '0'` right after navigation.
- **Fix:** animate **transform only** (a subtle slide), never opacity, in both `@keyframes page-enter` and `@keyframes stagger-in`. A paused slide is still fully visible. Verified: `.app-content` opacity is now `1` at 50/400/1500ms after navigation, where it used to be `0`. **Lesson: never gate content visibility on an entrance animation that can be paused.**
- **Diagnosis method (reusable):** the live bundle hash matched the local build (so live = latest code), demo rendered fine, and a read-only structural query of the real account's data (`server/serve-prod.mjs` exists for prod-build repro; a throwaway diag script hit Atlas via `server/.env`) showed the data is **clean** (6 areas, 6 goals all with valid period/parent/area refs, 1 person, 0 delegations) — proving it was NOT a data crash. That's what pointed back at the animation.

  1. **Root Directory MUST be repo root** (`./`), not `client/`. If it's `client/`,

     matched single-segment paths in practice (multi-seg → platform NOT_FOUND). Fix:
     `api/index.ts` + vercel.json `rewrites` `/api/(.*)` → `/api` (original URL is
     preserved, Express matches its `/api`-prefixed routes), then `/(.*)` → index.html.
  3. **Import the server with a DYNAMIC `import()`, not a static top-level import.**
     A static `import { createApp } from '../server/src/app.js'` crashed the function
     at load (FUNCTION_INVOCATION_FAILED); `@vercel/node` only bundles the

     alive (static serving is the CDN's job here anyway). `SERVE_CLIENT=false` also
     keeps the block off.
  5. buildCommand is `npm run build --workspace client` (the function bundles the
     server itself; no server `tsc` needed for Vercel). Client calls API via
     relative `/api` (`client/src/api/client.ts`) so same-origin needs no `VITE_*`.

## Architecture map

**Server (`server/src/`)** — Express + TS (NodeNext ESM), Mongoose, JWT. Every doc scoped to `userId`.
- Models: `User` (+ `routine{sleep/commute/work Minutes, workdays[]}` + `onboarded`), `LifeArea`, `FunctionTrack`, `Goal`, `Task`, `Interruption`, `TimeLog` (now unused by budget — kept), `Reconciliation`, `GoogleAccount` (OAuth tokens, **plaintext — encrypt before multi-user**), `BudgetExclusion` (muted calendar series).
- `Task` fields: areaId (optional only for chore_session), **kind (task|chore|chore_session)**, trackId?, goalId?, title, status (not_started|in_progress|done|deferred|blocked), source, estimateMinutes, **loggedMinutes**, scheduledAt?, **dueAt? + deadlineType(soft|hard)**, delegateName?, deferredCount, **completedAt?**, **day** (YYYY-MM-DD, the day it shows in Today), timestamps (createdAt).
- `Goal` fields: areaId, text, icon, pct (0-100), color, **period (weekly|monthly|half_year|annual)**. Full CRUD route `/api/goals` already exists; `Task.goalId` links a task to a goal.
- Routes (`/api`): auth, me (`/settings` saves routine + flips onboarded), areas, tracks, goals, tasks (CRUD + `/:id/defer`; PATCH stamps completedAt on done), interruptions, timelogs, **today** (returns the day + availableMinutes + today's tasks **plus all unfinished other-day tasks** — no destructive rollover), **budget** (`?scope=day|week|month`), **reconciliations** (`/`, `/due`, POST), **google** (`/status`, `/auth-url`, `/callback` signed-state, accounts CRUD, `/events`, `/exclude`).
- Services: `budget.ts#computeBudget` (sums task.loggedMinutes/estimate per range), `availability.ts` (availableForDay/Range from routine — work only deducts on workdays; 24h before onboarding), `google.ts` (plain-fetch OAuth + calendar fetch, recurring expanded, seriesKey).
- `util/day.ts`: local day keys, `addDays`, `scopeRange`, `weekOfYear`, `daysBetween`, `completedPeriod`.

**Client (`client/src/`)** — React PWA. The cockpit is driven by `today/useToday.tsx` (reducer + context) over a **repo seam** `today/repo.ts`: `localRepo` (demo seed) vs `apiRepo` (persisted) chosen by `auth.isGuest`. Components in `components/today/*`.
